# Phase 13D-A — Product UI promotion audit

The default Qase application is the product. `?studio=mock` is a controlled host wrapper used to demonstrate how those same Qase components fit inside Drytis Studio.

## Shared product behavior

- Customer navigation and Advanced tools
- Collapsible recent-tests sidebar
- Running browser hierarchy and initial Plan selection
- Current activity, progress, findings access, Stop, and elapsed time
- Results-first completion state and saved preview thumbnail
- Findings selection, report hierarchy, feedback, and retest
- Closed Run details disclosure for device, browser, execution, session, and model usage
- Responsive workspace navigation and light/dark themes

## Studio wrapper behavior

- Drytis host rail
- Project and AI context pane
- Context collapse and resize behavior
- Studio tool header and demo marker
- Host-specific workspace sizing
- Reuse of the host project URL in launch dialogs

## Promoted from mock-only to shared

- Recent-tests sidebar collapse and persistence
- Removal of duplicate desktop Start testing actions
- Removal of the duplicate onboarding checklist
- Removal of permanent token, execution, and session presentation
- Plain-language Preview and runtime status labels
- Concise empty-state presentation

## Kept out of standalone Qase

- Drytis navigation
- Drytis project conversation and context controls
- Studio context resize separator
- Studio demo badge
- Host-only panel suppression and embedded grid sizing
